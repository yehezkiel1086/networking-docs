# Computer Networks Lab Reports & Documentation

Comprehensive lab reports and configuration documentation for Computer Networks modules.

---

## Modules Overview

| # | Topic & Directory | Key Topics & Technologies |
|---|-------------------|---------------------------|
| **01** | [**01-packet-analysis-wireshark**](./01-packet-analysis-wireshark/README.md) | Wireshark packet capture analysis, FTP command & sequence/ACK inspection, UDP checksum calculation, a1z26 cipher decoding, HTTP/Telnet credential extraction, Wireshark display filter queries. |
| **02** | [**02-dns-and-web-servers**](./02-dns-and-web-servers/README.md) | BIND9 DNS Master & Slave configuration, reverse DNS (`in-addr.arpa`), subdomain delegation, Nginx Load Balancer (Round Robin), Apache2 virtual hosts, URL rewriting (`.htaccess`), basic authentication (`htpasswd`), directory listing control. |
| **03** | [**03-dhcp-load-balancing-worker-tuning**](./03-dhcp-load-balancing-worker-tuning/README.md) | DHCP Server (`isc-dhcp-server`) & Relay (`isc-dhcp-relay`), Apache Benchmark (`ab`) load testing, Nginx load balancing algorithm comparisons (Round Robin, Least Connection, IP Hash, Generic Hash), reverse proxy routing, MariaDB setup, multi-worker Laravel deployment, PHP-FPM process manager tuning (`pm.max_children`, etc.). |
| **04** | [**04-subnetting-cidr-vlsm**](./04-subnetting-cidr-vlsm/README.md) | Subnet design, CIDR aggregation on GNS3, VLSM (Variable Length Subnet Masking) tree calculation, Network ID / Broadcast ID / Subnet Mask allocation, and routing on Cisco Packet Tracer. |
| **05** | [**05-advanced-routing-and-iptables-firewall**](./05-advanced-routing-and-iptables-firewall/README.md) | Multi-subnet VLSM topology, inter-router static routing, DHCP Relay infrastructure, IPTables firewall security (SNAT without MASQUERADE, TCP/UDP port filtering, ICMP `connlimit`, IP range SSH restriction, time-based access control, nth mode load distribution, port scan detection via `hashlimit`, and syslog drop logging). |
